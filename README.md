# DriftWM Dotfiles

Awesome ArchLinux driftwm ironbar helix rice, heavily styled with Catppuccin Mocha everywhere. To install, run:

```bash
git clone https://github.com/gh0st-8221/driftwm-dotfiles
cd driftwm-dotfiles
chmod +x ./install.sh
./install.sh
```

Package installation won't work on non-Arch distros, and systemd might fail if you use something cooler like OpenRC or runit.
